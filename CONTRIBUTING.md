# Contributing

## Setup

```bash
pip install -e .[dev]
pytest -q
```

## Style

- short comments, plain words
- no banners, no em dashes in code
- keep functions small
- add a test for each rule tweak

## PRs

1. fork and branch
2. add test in `tests/`
3. run `pytest -q` and `sentinel demo`
4. explain what real folder you tried it on

Thanks.
